#%% md 
<h1 style="text-align: left;">一 项目简介</h1><h2 style="text-align: left;">1.1项目背景</h2><p>随着电商市场竞争加剧，深入了解消费者行为、挖掘用户购物偏好与忠诚度成为提升用户留存、优化商品策略和店铺运营的关键。本数据集包含京东平台18万+条用户行为记录，涵盖用户信息、商品信息、店铺信息等多维数据，为构建全面的用户分析提供了基础。</p><h2>1.2项目目标</h2><p>①构建用户画像：从年龄、性别、会员等级、城市等级等维度描述用户特征，分析不同人群的购物偏好与活跃规律。</p><p>②探究商品属性影响：分析品类、品牌、新品上市时间等因素与用户购买行为的关系，挖掘热门品类与品牌格局。</p><p>③评估用户忠诚度：采用RFM模型对用户进行分层，识别重要价值用户、潜力用户及流失风险用户等。</p><p>④构建行为漏斗：量化用户从浏览、加购、下单到关注的转化路径，定位转化瓶颈。</p><p>⑤分析店铺运营指标：研究店铺评分、粉丝数、会员数与销量的相关性，对比新老店铺的销售表现，并考察类目竞争结构。</p><p>⑥输出可视化仪表板：基于分析结果，利用Tableau构建可视化看板，直观展示关键指标。</p>

<h2><strong>3.4 数据格式处理</strong></h2><p>关于“action_date”，“customer_register_date”，“product_market_date”，“shop_register_date”四个时间变量。</p><p>要求：</p><p>①action_date &gt;=customer_register_date 用户必须先注册，才能产生行为；</p><p>②action_date &gt;=product_market_date用户只能对已上市的商品进行操作；</p><p>③action_date &gt;=shop_register_date用户只能在店铺注册后才能访问该店铺商品；</p><p>④product_market_date &gt;=shop_register_date商品必须在店铺注册之后才能上架。</p><pre><code>SET SQL_SAFE_UPDATES = 0;   
DELETE FROM jd_database_new   
WHERE action_date &lt; customer_register_date   
   OR action_date &lt; product_market_date   
   OR action_date &lt; shop_register_date   
   OR product_market_date &lt; shop_register_date;   
SET SQL_SAFE_UPDATES = 1;</code></pre><img src="https://cdn.kesci.com/upload/1773072768288_1.png?imageView2/0/w/960/h/960"><p>为了方便后续使用，将各时间格式改为“年-月-日”的格式。</p><pre><code>SET SQL_SAFE_UPDATES = 0;

<h3>4.1.2&nbsp;用户活跃分析</h3><p>因为大多数业务存在明显的周期性波动。例如，周一至周五流量高，周六周日流量低（或者像娱乐类应用反之）。因此计算每周活跃用户数的pv（Page View，页面浏览量）、uv（Unique Visitor，独立访客数）、pv/uv（浏览深度）。</p><p>第一步：为了方便我们直接从起始日开始，7天为一周。先做编号操作，即先按时间顺序编号比如前七天编号为0，再七天编号为1...</p><pre><code>WITH t1 as (   
SELECT   
    action_date,   
    FLOOR(DATEDIFF(action_date, '2018-02-01') / 7) AS num,   
    COUNT(customer_id) AS pv,   
    COUNT(DISTINCT customer_id) AS uv   
FROM   
    jd_database_new   
GROUP BY action_date   
)</code></pre><p>第二步：</p><pre><code>①(SELECT MIN(action_date) FROM jd_database_new) 开始日期；</code></pre><pre><code>②(SELECT MAX(action_date) FROM jd_database_new) 结束日期；</code></pre><pre><code>③DATE_ADD((SELECT MIN(action_date) FROM jd_database_new), INTERVAL (num 7) DAY) 计算每周的起始日期：起始日期+num 7；</code></pre><pre><code>④DATE_ADD((SELECT MIN(action_date) FROM jd_database_new), INTERVAL (num * 7 + 6) DAY) 计算每周的终止日期：每周起始日期+6。</code></pre><p>带入下方代码即可：</p><pre><code>SELECT   
    CONCAT(start_date, ' 至 ', end_date) AS date,   
    PV AS "每周PV",   
    UV AS "每周UV",   
    ROUND(PV / UV, 2) AS "pv/uv"   
FROM (SELECT   
        num,   
        ③ AS start_date,   
        IF(④ &gt; ②, ②, ④) AS end_date,   
        SUM(pv) PV,    
        SUM(uv) UV   
     FROM t1   
     GROUP BY num   
     )t2;</code></pre><img src="https://cdn.kesci.com/upload/1773193917631_1.png?imageView2/0/w/960/h/960"><p></p>

<h3>4.1.3&nbsp;用户留存分析</h3><p>计算用户的平均次日留存率：</p><pre><code>SELECT   
    ROUND(SUM(IF(t2.date IS NOT NULL, 1, 0)) / COUNT(t1.date), 4) avg_ret   
FROM   
    (SELECT DISTINCT   
        customer_id, action_date date   
    FROM   
        jd_database_new) t1   
LEFT JOIN   
    (SELECT DISTINCT   
        customer_id, DATE_SUB(action_date, INTERVAL 1 DAY) date   
    FROM   
        jd_database_new) t2   
ON t1.customer_id = t2.customer_id AND t1.date = t2.date   
WHERE t1.date &lt; (SELECT MAX(action_date) FROM jd_database_new);</code></pre><p>计算每日新增用户的平均次日留存率：</p><pre><code>SELECT   
    ROUND(SUM(IF(t2.date IS NOT NULL, 1, 0)) / COUNT(t1.date), 4) new_avg_ret   
FROM   
    (SELECT   
        customer_id, MIN(action_date) date   
    FROM   
        jd_database_new   
    GROUP BY customer_id) t1   
LEFT JOIN   
    (SELECT DISTINCT   
        customer_id, DATE_SUB(action_date, INTERVAL 1 DAY) date   
    FROM   
        jd_database_new) t2   
ON t1.customer_id = t2.customer_id AND t1.date = t2.date   
WHERE t1.date &lt; (SELECT MAX(action_date) FROM jd_database_new);</code></pre><p>结果如下：</p><table style="width: 341px;"><colgroup><col style="width: 197px;"><col style="width: 144px;"></colgroup><tbody><tr><td colspan="1" rowspan="1" colwidth="197"><p style="text-align: center;">avg_ret</p></td><td colspan="1" rowspan="1" colwidth="144"><p style="text-align: center;">0.0278</p></td></tr><tr><td colspan="1" rowspan="1" colwidth="197"><p style="text-align: center;">new_avg_ret</p></td><td colspan="1" rowspan="1" colwidth="144"><p style="text-align: center;">0.0169</p></td></tr></tbody></table><p></p>
